# Memento: 60-second film script

Fourteen short lines, about 45 seconds of speech. Read it calmly, like telling a friend about something
you're proud of. Leave a full breath (about one second) between lines; those are my edit points.

| # | Line | On screen |
|---|------|-----------|
| 1 | This is a memory: a Markdown page in GBrain. | The page `projects/monorepo-deploy.md` |
| 2 | When you chat, your agent reads it. That's how it remembers. | A chat; the agent answers from the page |
| 3 | This one says our deploy is blocked by a Next.js bug. | The line "blocked on vercel/next.js#89207" lights up |
| 4 | But memory only speaks when you ask, and nobody checks a GitHub issue every six hours. | The issue, days passing, unchecked |
| 5 | So Memento gives every memory a recipe. | `recipe:` unfolds in the front matter |
| 6 | A few lines of Python in the front matter, written by River the moment the memory is saved. | River types the recipe |
| 7 | Every six hours, it fetches the issue. | `@at(..., every=hours(6))` and `fetch(...)`: the checks start |
| 8 | Is it really fixed? That's not a regex, it's a judgment. Jev makes it in a hundred milliseconds. | `issue.says(...)` highlighted |
| 9 | Still open, fix in review? No. | Check: 0.04 |
| 10 | Closed, and the fix is released? Yes. | Check: 0.97 |
| — | *(stay silent for two seconds)* | The notification: "Next.js fixed #89207. Your monorepo deploy is unblocked." |
| 11 | Then River updates the memory and retires the check. | The page rewrites; the recipe retires |
| 12 | Memory that doesn't just remember. | |
| 13 | It watches, it judges, it tells you. | |
| 14 | Memento. Proactive memory for GBrain. | The name |

## Recording

- **One continuous take of all 14 lines.** If you stumble, pause and say the whole line again. Two clean
  takes of each line is even better; I'll pick.
- **Camera:** landscape, 4K if you can (1080p is fine), 30 or 60 fps, at eye level, on something steady.
  Waist-up, centred, with room around you. Look into the lens.
- **Background:** a plain, evenly lit wall. **Light:** face a window or a soft light, nothing bright behind you.
- **Clothes:** solid dark colour, no stripes or logos.
- **Sound matters most:** a quiet room, mic close (earbuds mic or lav beats the phone across the room).
  If audio is recorded separately, clap once at the start.

Send the raw mp4, untrimmed. I'll cut it to the beats and re-time the animation and music to your voice.
